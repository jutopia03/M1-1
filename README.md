# M1-1 — AI 데이터 분석: 데이터 기반 트렌드 분석

코디세이 미션 M1-1. 시계열 데이터를 정제·분석하고 인사이트 리포트를 작성한다.

## 결과물

- [`REPORT.md`](REPORT.md) — 분석 리포트 (본 과제의 핵심 산출물)
- `analysis.ipynb` — 분석 코드
- `images/` — 리포트에 삽입된 시각화
- `data/` — 원본 데이터 (또는 수집 방법은 REPORT.md 3장 참조)

## 실행 방법

```bash
pip install -r requirements.txt
jupyter notebook analysis.ipynb
```

Python 3.10 이상 필요.
